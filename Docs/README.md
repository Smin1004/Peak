# 프로젝트 문서 폴더 안내

PEAK 모작 프로젝트 「Peak」(가칭) 개발 문서 모음.

- **목적**: 기획 세션(브레인)과 워커 세션(구현)이 같은 그림을 보게 하는 것. 사람 1명 + AI 에이전트 여러 세션 체제
- **원칙**: 문서에 근거 없는 코드 작성 금지. 구현 전 해당 분야 문서를 반드시 읽을 것
- **원작**: PEAK (Aggro Crab × Landfall, 2025-06-16, Steam). 배포하지 않는 모작·학습 프로젝트

## 읽는 순서

**사람 (개발자 본인):**
1. `SUMMARY.md` — 전체 그림
2. `100_game_design.md` — 게임 룰
3. `300_roadmap.md` — 지금 어느 마일스톤인지
4. 해당 마일스톤의 200번대 문서

**AI 워커 세션:**
1. `SUMMARY.md` → `100_game_design.md` → `201_common.md` (필독 3종)
2. 프롬프트에 지정된 담당 문서 (`202`~`206`)
3. `101`, `102`는 스코프 판단용 참고 — 코어가 아님. 프롬프트 범위 밖 기능은 구현하지 않는다

## 문서 규칙

- 기획 변경은 **문서 먼저, 코드 나중**. 변경 시 이 파일의 변경 이력에 한 줄 추가
- 코어(100)와 확장(101)의 경계 유지. 코어를 넓히려면 `300_roadmap.md`의 티어와 함께 조정
- 문서 안의 **⚠ 확인 필요** 표시는 제안 상태의 수치·규칙. 플레이 검증 후 확정하고 표시를 지울 것
- 튜닝 수치의 진실은 ScriptableObject 에셋이다. 문서는 **초기값과 근거**만 적는다 (`201_common.md` 4장)
- 문서 수정은 기획 세션 담당. 워커 세션은 자기 프롬프트 범위 밖의 문서를 수정하지 않는다. 구현 중 문서와 다르게 해야 했다면 완료 보고에 적는다
- 각 문서 하단의 "관련 문서" 링크로 정황 파악
