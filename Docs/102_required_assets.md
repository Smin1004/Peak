# 102 — 필요 에셋과 플레이스홀더 방침

> 아트 리소스를 구하기 어려운 상황이므로 **처음부터 프리미티브 + 단색**으로 만들고, 로직을 건드리지 않고 나중에 교체할 수 있는 구조를 강제한다.
> 이 문서는 "무엇을 나중에 바꿀 것인가"의 목록이자, 그때 로직이 안 깨지게 하는 규칙이다.

## 1. 기본 방침

| 항목 | 방침 |
|---|---|
| 모델 | Unity 프리미티브(캡슐·큐브·실린더·구)만. 외부 모델 없음 |
| 머티리얼 | URP Lit 단색. 색은 **테마 ScriptableObject**(`VisualTheme`)에서만 가져온다. 코드 하드코딩 금지 |
| 지형 | 생성 메시 + 바이옴별 정점 색(vertex color). 텍스처 없음 |
| 이펙트 | 파티클 최소 (캠프파이어 불, 안개 경계). 나머지는 색 변화로 표현 |
| 애니메이션 | 없음. 상태는 캡슐 기울기·색으로 표현 (기절 = 눕힘, 등반 = 벽에 붙음) |
| 오디오 | T0·T1 없음. T2에서 추가. 단 **오디오 호출 지점은 처음부터** `AudioHook.Play("id")` 로 남겨둔다 |
| UI | uGUI + TextMeshPro, 단색 패널, 둥근 모서리 없음. 한글 폰트 1종 |
| 폰트 | Pretendard (이전 프로젝트 사용, OFL) ⚠ 확인 필요 — 프로젝트에 복사 필요 |

## 2. 교체 가능 구조 규칙 (모든 프리팹에 적용)

```
Prefab Root            ← 로직·콜라이더·NetworkObject. 스크립트는 여기만 본다
 └─ Visual             ← 자식. 프리미티브 메시·머티리얼. 교체 대상
     └─ (부속 파츠)
```

1. 스크립트는 `Visual` 내부의 컴포넌트를 **직접 참조하지 않는다**. 상태 표현이 필요하면 `IVisualState` 류 인터페이스로 `Visual` 루트에 통지
2. 콜라이더는 Root에. `Visual`은 콜라이더 없음 (교체 시 물리 변화 방지)
3. 색은 `VisualTheme` 에셋 → `MaterialPropertyBlock` 으로 적용. 머티리얼 에셋을 직접 수정하지 않는다
4. 크기 기준: 캐릭터 캡슐 높이 1.8 m, 반지름 0.35 m. 모든 오브젝트 스케일은 이 기준에 맞춘다 (나중에 모델 교체 시 스케일 기준)

## 3. 플레이스홀더 목록

| 대상 | 플레이스홀더 | 교체 우선순위 |
|---|---|---|
| 플레이어 | 캡슐 + 앞면 표시용 작은 큐브(코). 플레이어별 색 | 1 |
| 지형 | 생성 메시, 바이옴 정점 색 (해변 모래색 / 밀림 초록 / 고산 흰색 / 정상 회색) | 2 |
| 발판 (경로 노드) | 지형에 포함. 디버그 시 반투명 원판 표시 | — |
| 캠프파이어 | 실린더(장작) + 파티클(불) + 반경 표시 링(디버그) | 3 |
| 가방 | 큐브 (갈색). 열리면 색 변화 | 3 |
| 아이템 | 아이템별 프리미티브 + 색: 로프=실린더 갈색, 피톤=얇은 큐브 은색, 붕대=큐브 흰색, 음식=구 빨강, 랜턴=실린더 노랑, 배낭=큐브 초록, 조명탄=실린더 빨강, 인형=캡슐 소형 | 3 |
| 로프 | LineRenderer + 세그먼트 콜라이더 | 4 |
| 안개 | 구체 메시(내부 렌더) + URP 포그 + 경계 파티클 | 4 |
| 위험 구역 | 반투명 색 볼륨 (디버그), 릴리스 시 비표시 | — |
| 정상 표식 | 큰 실린더 + 깃발(쿼드) | 5 |
| 헬기 연출 | 큐브 1개가 내려왔다 올라감 | 5 |
| UI | 단색 바·패널 | 5 |
| 오디오 | 없음 | 6 |

## 4. 추후 교체 시 체크리스트

- [ ] `Visual` 자식만 교체했는가 (Root 컴포넌트 변경 없음)
- [ ] 캡슐 기준 스케일과 맞는가
- [ ] 콜라이더가 Root에 그대로인가
- [ ] 색을 테마에서 가져오는가 (모델에 텍스처가 있으면 테마 무시 옵션)
- [ ] 애니메이션이 필요하면 `IVisualState` 구현체가 Animator를 구동 (로직은 모름)
