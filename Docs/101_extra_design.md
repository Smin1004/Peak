# 101 — 확장 기획 (T2, 코어 아님)

> 코어(`100_game_design.md`)가 성립한 뒤에 얹는 것들. **여기 있는 것은 워커 프롬프트에 명시되기 전까지 구현하지 않는다.**
> 순서는 `300_roadmap.md` M6 기준 우선순위. 원작 자료는 peak.wiki.gg 기준 (2026-09 시점).

## 1. 교대 바이옴 (원작 Final Ascent 기준 구성)

원작은 고정 1 + 교대 4쌍 + 정상. 시드가 각 쌍에서 하나를 고른다.

| 순서 | A | B | B의 특징 |
|---|---|---|---|
| 1 | Shore (고정) | — | |
| 2 | Tropics (밀림) | **Roots** | 늪, 거대 버섯·나무 등반, 포자, 좀비 |
| 3 | Alpine (고산) | **Mesa** | 사막, 더위, 선인장(가시), 회오리 |
| 4 | Caldera (화산) | **Gloom** | 안개 늪, 졸음 안개, 파리지옥 |
| 5 | Kiln (정상 전) | **Citadel** | 성채, 화살·철퇴·롤러 함정 |

- 구현 우선순위: Mesa(더위·가시만 추가하면 됨) → Roots → Gloom → Citadel(함정 = 별도 시스템)
- 생성 관점: 바이옴 = `BiomeDef` 파라미터 세트이므로 새 바이옴 = 새 에셋 + 전용 위험물 프리팹 (`203` 5장)

## 2. Ascent 난이도 (원작 1~8, 누적 적용)

| 단계 | 원작 수정자 | 우리 구현 난이도 |
|---|---|---|
| Tenderfoot | 안개 없음 | 코어 옵션 (안개 OFF) |
| PEAK | 기본 | 코어 기본 |
| Ascent 1 | 낙하 피해 증가 | 쉬움 (배율) |
| Ascent 2 | 허기 가속 | 쉬움 (배율) |
| Ascent 3 | 아이템 무게 증가 | 쉬움 (배율) |
| Ascent 4 | 정상 조명탄 미지급 (직접 찾아 가져가야 함) | 보통 (아이템 스폰 규칙) |
| Ascent 5 | 밤마다 추위 부여 | 어려움 (낮/밤 필요, 10장) |
| Ascent 6 | 등반 스태미나 소모 증가 | 쉬움 (배율) |
| Ascent 7 | 저주 상태로 시작, 부활 시 저주 증가 | 보통 (저주 필요, 4장) |
| Ascent 8 | 조명탄 대신 4개 바이옴의 부적 수집 | 어려움 (퀘스트 아이템) |

- 1·2·3·6 은 `GameTuning` 배율만으로 구현 가능 → M6 첫 작업 후보
- 로비 UI에 난이도 선택 추가 (`204`)

## 3. 요리 (캠프파이어)

- 아이템을 들고 캠프파이어에 E → 몇 초 후 "구운 X"로 변환
- 변환 예 (원작 참고): 독 열매 → 독 제거, 생 음식 → 허기 해소량 증가, 너무 오래 구우면 탄 음식(허기 해소 감소, 더위 부여)
- 구현: `ItemDef.cookedVariant` 1필드 + 캠프파이어 상호작용 분기. 데이터만 있으면 작음

## 4. 확장 상태이상

| 상태이상 | 색 | 원인 | 해소 | 자연 회복 |
|---|---|---|---|---|
| 포자 Spores | 보라 | 버섯 열매, 포자 구름, 좀비 | 해독제, 약초 | 45초 후 초당 0.5 |
| 졸음 Drowsy | 회청 | 다트, 낮잠 열매, Gloom 안개 | 에너지 드링크 | 10초 후 초당 1.5 |
| 가시 Thorns | 갈색 | 선인장, 가시 열매 | 수동 제거 (하나씩 클릭) | 없음. 가시 1개 = 5 |
| 저주 Curse | 짙은 보라 | 고대 석상, Ascent 7~8, 부활 | 만병통치약 | 없음 |
| 석화 Petrify | 회색 | 부적, 석화석 | 캠프파이어 −20 | 없음. 보너스 바를 잠식하는 특수형 |
| 화살 Arrow | 노랑 | Citadel 함정 | 뽑기 (부상 12.5) | 없음. 1개 = 7.5 |

- 구현은 코어의 `StatusEffectDef` 에셋 추가로 대부분 해결. 가시·화살은 "물리 오브젝트가 붙는" 특수형이라 별도 작업

## 6. 배지·코스메틱

- 배지 = 도전과제 (예: 낙하 없이 바이옴 통과, 나팔 100회, 솔로 클리어). 배지가 코스메틱(모자·의상 색)을 해금
- 저장: 로컬 JSON (`Application.persistentDataPath`). 클라우드 없음
- 코스메틱은 프리미티브 캐릭터라면 **색·모자 프리미티브** 수준으로 시작

## 7. 일일 시드

- 원작: 매일 17:00 UTC 시드 갱신, 전 세계 동일 맵
- 우리: 서버 없음 → `seed = hash(UTC 날짜)` 로 로컬 계산. 같은 날 같은 산. 로비에 "오늘의 산" 버튼
- 코어의 시드 입력 UI 위에 얹는 버튼 1개

## 8. 액티브 래그돌 캐릭터

- 원작의 손맛(휘청거림, 넘어짐)은 액티브 래그돌에서 온다
- 우리 1차는 캡슐 컨트롤러. 래그돌은 **낙하·기절 연출에만** 먼저 적용 (Ragdoll 상태에서 물리 전환), 조작 중 래그돌은 후순위
- 네트워크: 래그돌은 오너 시뮬레이션 + 위치만 동기화

## 9. 이모트·근접 보이스

- 이모트: 휠 UI + 애니메이션(프리미티브면 점프·회전 정도). 낮은 우선순위
- 근접 보이스: 코어에서 제외. 필요 시 Vivox 검토. 디스코드로 충분하다는 판단이 기본

## 10. 낮/밤과 날씨

- Ascent 5 를 위해 필요. 시간 경과에 따라 조명·추위 구역 전역 적용
- 눈보라(Alpine), 회오리(Mesa)는 바이옴 위험 요소 확장으로 취급
