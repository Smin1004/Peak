# SUMMARY — 프로젝트 요약

> **제목**: Peak (가칭 — 원작 PEAK 모작)
> **한 줄 컨셉**: 1~4인이 절차 생성된 산을 **스태미나 바 하나**에 의지해 협력하며 오르는 1인칭 등반 협동 게임. 원작 PEAK(Aggro Crab × Landfall, 2025)의 코어를 재현한다.

## 기본 정보

| 항목 | 내용 |
|---|---|
| 장르 | 3D **1인칭** 협동 등반 / 서바이벌 (원작 동일, 시점 토글 없음 — `301` D16) |

## 코어 루프

```
로비 (방 만들기 / 참가 코드) → 해변 캠프파이어(점화됨)에서 시작
   ↓
┌→ 바이옴 등반 — 아이템 수집, 허기·부상 관리, 로프·피톤으로 서로 길 내기
│     ↓
│  다음 캠프파이어 도달 → 전원 집결 → 점화 (회복 · 안개 정지 · 다음 바이옴 개방)
└──┘ × 바이옴 N개
   ↓
정상 도달 → 조명탄 점화 → 클리어   (전원 사망 → 실패)
```

## 게임의 핵심 긴장 — 왜 재밌는가

- **자원이 하나뿐**: 체력이 없다. 스태미나 바 하나를 허기·부상·추위가 잠식한다. 모든 판단이 "이 바를 얼마나 남길까"로 수렴한다
- **협동의 필연성**: 한 명이 올라가 로프를 내리면 나머지는 스태미나를 아낀다. 기절한 동료는 팀이 먹이고 업어야 산다
- **시간 압박**: 안개가 아래에서 올라온다. 멈추면 얼고, 서두르면 떨어진다
- **매번 다른 산**: 시드 기반 절차 생성. 같은 시드 = 같은 산

## 티어와 MVP 범위 (상세 `300_roadmap.md`)

| 티어 | 내용 | 성립 조건 |
|---|---|---|
| **T0 학습용 최소** | 싱글, 절차 생성 산 (바이옴 1 + 정상), 등반·스태미나·낙하 부상·허기, 캠프파이어, 음식·붕대 | 혼자 20분 플레이해도 재밌다 |
| **T1 협동 MVP** | 온라인 2~4인, 바이옴 3 + 정상, 안개, 전원 집결 점화, 기절·사망·부활, 아이템 8종, 텍스트 채팅 | 친구와 한 판 완주 |
| **T2 완성작** | 교대 바이옴 4쌍, Ascent 난이도, 요리, 확장 아이템·상태이상, 배지/코스메틱, 일일 시드, 사운드·연출 | 원작 경험의 재현 |

목표는 T2, 최소 성공은 T0. **티어 경계마다 항상 플레이 가능한 상태**를 유지한다.

## 기술적 핵심 결정

- **절차 생성은 경로 우선(route-first)**: 등반 경로 그래프를 먼저 만들고 지형을 그 위에 씌운다. 생성 후 스태미나 제약 솔버로 검증, 실패 시 보정 → `203_procgen.md`
- **생성은 시드 결정적**: 호스트가 시드만 보내고 각 클라이언트가 같은 산을 로컬 생성. 지형 데이터 전송 없음 → `203`, `205`
- **처음부터 멀티플레이 구조**: M0부터 NGO 호스트 모드로 실행하고 게임플레이 코드는 NetworkBehaviour 기준으로 작성. Relay·참가 코드는 M4에 붙인다 (`301` D13) → `205`
- **1인칭 전용**: Cinemachine 3 하드락 카메라, 눈높이 1.6 m, 자기 몸은 그림자만, 등반 중 프리미티브 손 (M1). 발밑이 안 보이는 긴장이 팀원 시야·로프의 가치를 만든다 → `202` 12장, `301` D16
- **스태미나 바 = 유일한 자원**: 체력 없음. 상태이상은 바를 잠식하는 (종류, 양) 목록 → `100` 4장, `202` 4장
- **튜닝 수치는 ScriptableObject에**: 문서는 초기값과 근거만 → `201` 4장
- **시각은 교체 가능하게**: 프리팹 = 로직 루트 + Visual 자식. 프리미티브 + 테마 SO → `102`
- **씬 3개**: Boot(매니저) / Lobby / Game(생성된 산). 샌드박스 씬은 별도 → `201` 2장
