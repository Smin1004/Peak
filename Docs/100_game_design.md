# 100 — 전반 기획 (코어)

> 게임의 룰과 구조를 정의하는 코어 기획 문서. 이 문서의 내용이 우선순위의 기준이다.
> 원작 PEAK의 코어를 재현하되 **수치는 우리 것으로 다시 잡는다** (원작 수치는 참고값으로 병기).
> 확장 기획은 `101_extra_design.md`, 필요 에셋은 `102_required_assets.md`, 티어·마일스톤은 `300_roadmap.md`.

## 1. 원작 분석 — 무엇을 가져오고 무엇을 버리는가

| 항목 | 내용 |
|---|---|
| 장르 | 3D 1인칭 협동 등반 |

## 3. 런 루프

```
로비 (호스트: 시드·안개 ON/OFF · 참가: 코드)
   ↓
[생성] 시드로 산 생성 (전원 로컬, 205 4장)
   ↓
시작: 해변 캠프파이어 (이미 점화됨) + 시작 가방
   ↓
┌→ ① 바이옴 등반 ──→ ② 캠프파이어 도달 ──→ ③ 전원 집결 → 점화 ─┐
│   (안개 타이머 진행)     (안전 지대)          (안개 정지·구간 개방)  │
└───────────────────────────────────────────────────────────┘ × 바이옴 수
   ↓
④ 정상 구간 (짧고 수직) → 조명탄 → 결과 화면 (클리어 시간, 사망 횟수, 사용 아이템)
```

| 단계 | 설명 |
|---|---|
| 시작 | 첫 캠프파이어는 점화 상태. 반경 안에 시작 가방 N개 (`206_items.md` 3장). 튜토리얼 표지판 = 텍스트 |
| ① 바이옴 등반 | 캠프파이어 A → B 구간. 가방 수집, 위험 요소 회피, 서로 로프·피톤 설치. 안개 타이머는 A 점화 시점부터 (6장) |
| ② 캠프파이어 도달 | 반경 R_camp 안은 안전 지대: 허기 정지, 안개 침입 없음. 미점화 상태에서도 안전 |
| ③ 점화 | **조건: 살아 있는 모든 플레이어(기절자 포함)가 반경 안**. 유령(사망자)은 조건에서 제외. 아무나 E로 점화. 효과는 7장 |
| ④ 정상 | 마지막 구간. 조명탄을 정상 표식에 사용 → 헬기 연출(단순) → 결과 화면 |

- 체크포인트/리스폰은 **없다**. 원작과 같이 죽으면 부활 아이템뿐 (4.4장)
- 뒤로 내려가는 것은 자유. 단 이전 캠프파이어는 이미 안개에 잠겨 있다
- 결과 화면 → 로비로 복귀. 같은 방에서 재시작 가능 (시드 변경 가능)

## 4. 스태미나와 상태이상 — 게임의 유일한 자원

### 4.1 스태미나 바

| 규칙 | 내용 | 원작 참고 |
|---|---|---|
| 최대치 | 100 | 100 |
| 소모 | 등반 초당 `c_climb`, 달리기 초당 `c_sprint`, 점프 1회 `c_jump` | 수치 비공개 |
| 회복 | 지상 정지·이동 중 0.2초 후 초당 20. **등반 중 회복 없음**. 피톤·로프에 매달리면 회복 | 20/s |
| 0이 되면 | 등반·달리기 불가. **등반 중 0 → 손을 놓쳐 낙하** ("탈진 낙하" — 부상 가중, 4.5장) | 동일 |
| 보너스 스태미나 | 별도 예비 바. 음식·캠프파이어로 획득, **재생 없음**, 메인이 0일 때만 소모 | 동일 (사기) |

초기값 제안 (⚠ 확인 필요, 진실은 `GameTuning` 에셋): `c_climb` = 10/s, `c_sprint` = 5/s, `c_jump` = 10. 등반 속도 1.5 m/s → **한 번에 약 15 m** 오를 수 있다. 이 값이 `203_procgen.md`의 구간 높이 상한을 결정한다.

### 4.2 상태이상 — 바를 잠식하는 값

- 각 상태이상은 (종류, 양)이며 바의 **왼쪽부터 색 조각으로 채워진다**. 합계만큼 최대 스태미나가 줄어든다
- 합계는 200까지 누적 가능 (바 밖으로 넘친 만큼은 점선 표시). **합계 ≥ 100 이면 기절** (4.4장)
- 체력(HP)은 존재하지 않는다. "피해"는 전부 부상(Injury) 상태이상이다

| 상태이상 | 색 | 원인 | 해소 | 자연 회복 | 티어 |
|---|---|---|---|---|---|
| 허기 Hunger | 주황 | 시간 경과 (초당 `hunger_rate`) | 음식 | 없음 (증가만) | **T0** |
| 부상 Injury | 빨강 | 낙하(4.5장), 용암, 위험 생물 | 붕대 30, 캠프파이어 점화 20, 구급상자 100 | 없음 | **T0** |
| 무게 Weight | 회색 | 인벤토리 아이템 무게 합 | 버리기 | 즉시 반영 | T1 |
| 추위 Cold | 하늘 | 안개 속, 고산 눈보라 구역 | 랜턴 소지, 캠프파이어, 구역 이탈 | 노출 벗어나면 초당 `cold_decay` | T1 |
| 독 Poison | 초록 | 독 열매, 해파리 | 해독제, 구급상자 | 마지막 피해 30초 후 초당 0.4 | T1 |
| 더위 Heat | 주홍 | 용암 근접, 사막 | 물, 그늘 | 8초 후 초당 1.3 | T2 |
| 포자·졸음·가시·저주·석화 | — | `101_extra_design.md` 4장 | | | T2 |

초기값 제안 (⚠): `hunger_rate` = 0.06/s (원작 0.05/s — 우리 한 판이 짧으므로 약간 빠르게), `cold_decay` = 1.0/s.

### 4.3 상태이상의 적용 주체

- 허기: 각자 타이머
- 부상: 낙하는 본인 판정. 용암·생물은 **구역(Volume)** 또는 가해자가 대상에게 적용
- 추위·더위·독: 구역 안에 있는 동안 초당 누적 (구역 = 안개 구체, 눈보라 존, 용암 반경)
- 무게: 인벤토리 변화 시 즉시 재계산

### 4.4 기절과 사망

| 상태 | 진입 | 상태 중 | 탈출 |
|---|---|---|---|
| **기절 Unconscious** | 상태이상 합 ≥ 100 | 조작 불가, 쓰러짐. **팀원이 업어 운반 가능** (5.5장). 상태이상은 계속 변한다 (허기 증가, 추위 감소) | 합 < 100 이 되면 자동 기상 — 팀원이 음식·붕대를 **먹여주거나**, 추위 등이 자연 감소 |
| **사망 Dead** | 기절 후 `t_death`초 경과 / 즉사 조건 | 유령: 관전 카메라(자유 비행), 텍스트 채팅 가능, 상호작용 불가 | 스카우트 인형(부활 아이템)으로만 |

- 즉사 조건: 바다·용암에 빠짐, 맵 경계 밖. **낙하는 즉사시키지 않는다** (부상 최대 100 → 기절)
- `t_death` 초기값 60초 ⚠ 확인 필요 (원작 미확인). 안개 속 기절은 사실상 사망
- 사망 시 인벤토리는 그 자리에 드롭 (팀이 회수 가능)
- 부활: 스카우트 인형 사용 → 사용 위치에 사망자 1명(무작위) 부활, 상태이상 초기화, 인벤토리 비움. **솔로에서는 인형 미출현** (원작 동일)
- 전멸 = 게임 오버 → 결과 화면
- 싱글 플레이에서 기절 = 회복 수단이 없으면 사망. 자연 감소하는 상태이상(추위)이면 기상 가능

### 4.5 낙하 피해

- 착지 속도 `v` (m/s) 기준. `v < v_safe` → 0. `v_safe ≤ v ≤ v_max` → 부상 = lerp(5, 100). 그 이상은 100 (즉사 아님)
- **탈진 낙하** (등반 중 스태미나 0으로 놓침): 부상 ×1.5 ⚠ 확인 필요 (원작: "스스로 놓는 것보다 훨씬 아프다")
- 물에 착지: 피해 없음 (깊은 물 = 즉사 구역과 구분, 해변 얕은 물만 안전)
- 초기값 (⚠): `v_safe` = 8 m/s (약 3 m 낙하), `v_max` = 25 m/s (약 30 m 낙하)

## 5. 이동과 등반 (규칙 수준 — 구현은 `202_gameplay.md`)

### 5.1 지상
- 걷기, 달리기(스태미나), 점프(스태미나), 앉기(천장 낮은 곳). 경사 `θ_walk` 미만은 걸어서 오른다

### 5.2 등반
- **모든 지형 표면은 등반 가능**. 경사 `θ_walk` 이상이면 걸을 수 없고 등반해야 한다
- 좌클릭 홀드로 **조준점이 향한 앞의 표면**에 붙는다. 방향키로 표면을 따라 이동하고, 시선은 자유롭게 돌려 위의 길을 찾는다. 스태미나 초당 `c_climb` 소모, 회복 없음
- 손을 놓거나 스태미나 0 → 낙하
- 모서리에 닿으면 자동으로 올라선다 (맨틀)
- 재질 규칙 (T2): 얼음·젖은 바위는 소모 증가 또는 미끄러짐 → `101`

### 5.3 매달림 도구
- **로프**: 앵커(플레이어가 서 있는 발판 가장자리)에서 아래로 늘어뜨림. 잡으면 스태미나 소모 `c_rope` (등반보다 낮음), 매달린 채 회복 가능 ⚠. 팀 전체가 사용
- **피톤**: 벽에 박아 두면 그 위치에서 매달려 **회복**. 한 번에 1명
- 상세는 `206_items.md` 4장

### 5.4 상호작용
- E 키: 바라보는 대상에 상호작용 — 가방 열기, 아이템 줍기, 캠프파이어 점화, 조명탄 점화, 기절자 업기
- 아이템 사용은 좌클릭(들고 있는 아이템). **바라보는 팀원에게 사용** 가능 (붕대·음식을 먹여줌)

### 5.5 운반
- 기절자 또는 시체(⚠ 시체 유지 여부는 `301` Q3)를 업는다. 업은 동안 이동 속도 −30%, **등반 불가** ⚠ 확인 필요 (원작은 업고 등반 가능하다는 증언이 있어 확인 후 결정)
- 캠프파이어 점화 조건에 기절자가 포함되므로 운반이 협동의 핵심 동사가 된다

## 6. 안개 — 시간 압박

| 규칙 | 내용 | 원작 참고 |
|---|---|---|
| 시작 | 캠프파이어 점화 후 `t_fog`초 경과 **또는** 전원이 구간 높이의 `p_fog`%에 도달 | 1000초 |
| 형태 | 이전 캠프파이어 중심의 구체가 선형으로 커진다 → 실질적으로 아래에서 위로 올라오는 벽 | 동일 |
| 안개 속 | 추위 +2.5 / 2.4초, 시야 급감 (포그) | 동일 |
| 정지 | 다음 캠프파이어 점화 시 정지. 캠프파이어 반경은 항상 안전 | 동일 |
| 옵션 | 로비에서 안개 OFF (원작 Tenderfoot 상당). T0 기본 OFF | |

초기값 (⚠): `t_fog` = 바이옴 높이 × 5초/m (예: 100 m 바이옴 = 500초), `p_fog` = 60%. 안개 상승 속도는 "여유 있게 오르면 안 잡히고, 캠프파이어에서 오래 놀면 잡힌다"가 기준. 실제 값은 `203` 파라미터와 함께 플레이로 잡는다.

## 8. 바이옴

산은 **높이 밴드**로 나뉘고 밴드 경계마다 캠프파이어가 있다. 각 바이옴은 생성 파라미터(높이, 경사, 발판 밀도, 위험물, 팔레트)의 묶음이다 (`203_procgen.md` 5장).

| 순서 | 이름 (모작) | 원작 대응 | 지형 성격 | 위험 요소 | 티어 |
|---|---|---|---|---|---|
| 1 | 해변 Shore | Shore | 완만, 넓은 발판, 짧은 벽. 튜토리얼 구간 | 낙하, 해파리(독, 물가) | **T0** |
| 2 | 밀림 Jungle | Tropics | 가파른 벽, 등반 보조물(덩굴 = 로프 대용), 발판 좁음 | 독 열매, 벌집(근접 시 부상) | T1 |
| 3 | 고산 Alpine | Alpine | 눈, 좁은 능선, 긴 벽, 얼음 표면 | 추위(눈보라 구역), 얼음 | T1 |
| 4 | 화산 Caldera | Caldera | 용암 웅덩이 사이 점프, 검은 바위 | 용암(부상+더위), 안개 대신 용암 상승 | T2 |
| 5 | 정상 Peak | Kiln → Peak | 짧고 수직, 발판 희소, 조명탄 표식 | 추위 | **T0 (단순판)** / T2 (완성판) |

- 교대 바이옴(Roots, Mesa, Gloom, Citadel)은 `101` 1장
- T0 = 해변 + 정상. T1 = 해변 + 밀림 + 고산 + 정상. T2 = 4쌍 교대 + 정상

## 9. 아이템 (코어 목록 — 구현·수치는 `206_items.md`)

| 아이템 | 역할 | 티어 |
|---|---|---|
| 음식 (열매·통조림 통합) | 허기 해소. 일부 독 | **T0** |
| 붕대 | 부상 −30 | **T0** |
| 로프 스풀 | 앵커에서 로프 늘어뜨림 | T1 |
| 피톤 | 벽에 박아 회복 지점 | T1 |
| 랜턴 | 소지 시 추위 해소·빛 | T1 |
| 배낭 | 슬롯 +4 (착용) | T1 |
| 조명탄 | 정상에서 사용 = 클리어 | T1 (T0는 표식 상호작용으로 대체) |
| 스카우트 인형 | 사망자 부활 (멀티 전용) | T1 |
| 로프 캐논, 체인 런처, 안티로프, 마법 콩, 구급상자, 해독제, 만병통치약, 나침반, 나팔, 다이너마이트 | `101` 5장 | T2 |

- 인벤토리: 손 슬롯 `n_slots`(초기값 3 ⚠) + 배낭 슬롯 1. 배낭 착용 시 +4 ⚠ 확인 필요 (원작 슬롯 수 자료 불일치)
- 출처: **가방(Luggage)** — 경로 위·옆 발판에 생성, 열면 2~4개. 시작 지점 가방은 붕대·음식·로프 보장
- 무게: 아이템별 0 / 2.5 / 5 → 무게 상태이상

## 10. 협동 규칙 요약

1. 캠프파이어 점화는 **전원 집결** (기절자는 업어서라도)
2. 로프·피톤은 설치자와 무관하게 **팀 전체가 사용**
3. 아이템은 **바라보는 팀원에게 사용**하거나 던져서 전달
4. 기절자는 팀원이 **먹여서** 깨운다
5. 사망자는 **스카우트 인형**으로만 부활, 전멸이 게임 오버
6. 유령은 관전 + 텍스트 채팅으로 길 안내
7. 혼자 못 오르는 구간은 없다 (솔로 경로 항상 존재). 단 로프 있으면 지름길 (`203` 8장, T2)
