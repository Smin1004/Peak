# 204 — UI / HUD

> 기획 근거: `100_game_design.md` 3·4·7장. 아트 방침: `102` (단색 패널, 한글 폰트 1종).
> 소유 폴더: `Scripts/Runtime/UI/`, `Prefabs/UI/`. 마일스톤: M1 (스태미나 바), M3 (HUD 완성), M4 (로비).

## 1. 화면 흐름

```
Title/Lobby ──[방 만들기]──→ Room (호스트)  ──[시작]──→ Generating ──→ Game HUD ──→ Result ──→ Room
     └───────[코드 참가]────→ Room (참가자) ─┘                                        (재시작/나가기)
```

| 화면 | 구성 |
|---|---|
| **Lobby** | 닉네임, [방 만들기], 코드 입력 + [참가], [종료]. M0~M3 은 [싱글 시작] 버튼 하나로 대체 |
| **Room** | 참가 코드(크게, 복사), 플레이어 목록(색), 호스트 설정: 시드(숫자 입력 + [랜덤] + T2 [오늘의 산]), 안개 ON/OFF, 바이옴 프리셋(T0/T1), 난이도(T2). [시작]은 호스트만 |
| **Generating** | "산을 만드는 중…" + 시드 표시. 전원 생성 완료 대기 (`205` 4장) |
| **Game HUD** | 2장 |
| **Result** | 클리어/실패, 소요 시간, 도달 바이옴, 사망 횟수, [다시] (Room 으로) |
| **Pause** | Esc: 설정(감도·볼륨), [방 나가기] |

## 2. Game HUD

```
┌───────────────────────────────────────────────┐
│ 팀원 마커 (화면 밖 화살표 + 이름 + 거리)          │

│                                                │
│                    (+) 조준점 · 상호작용 프롬프트 │  "E 가방 열기"
│                                                │
│  [1][2][3] [배낭]        ┌────────────────┐    │

│                          │ ████░░░▒▒▒▒▒▒▒▒│    │  ← 스태미나 바

└───────────────────────────────────────────────┘
```

### 2.1 스태미나 바 (게임의 얼굴 — M1 부터)

- 폭 100% = 100 포인트. **왼쪽부터** 상태이상 색 조각이 `StatusEffectDef.order` 순서로 채워진다 (허기 주황 → 부상 빨강 → 무게 회색 → 추위 하늘 → 독 초록 …)
- 남은 폭 = 사용 가능 최대치. 그 안에서 현재 스태미나가 노랑으로 채워진다. 회복 중에는 밝게 깜빡임 없음 (조용하게)
- 합계가 100을 넘으면 바 오른쪽 밖으로 점선 테두리 조각이 이어진다 (최대 200)
- 보너스 스태미나: 바 위에 얇은 두 번째 바 (연두)
- 기절 임계 근처(사용 가능 < 15)면 테두리가 붉게 맥동 ⚠
- 구현: `StaminaBarView` 가 `PlayerState` 를 읽어 매 프레임 갱신. 조각은 `Image` 풀 (종류 수만큼)

### 2.2 그 외 요소

| 요소 | 내용 | 티어 |
|---|---|---|
| 인벤토리 슬롯 | 슬롯 3 + 배낭 슬롯. 선택 슬롯 강조. 아이템 아이콘 = 색 사각형 + 이름 (아이콘 없음) | T0 |
| 상호작용 프롬프트 | 조준 대상 이름 + 키 | T0 |
| 팀원 마커 | 화면 안: 머리 위 이름. 밖: 가장자리 화살표 + 거리. 기절 = 마커 빨강, 사망 = 회색 | T1 |
| 집결 카운터 | 캠프파이어 반경 안 생존자 수 / 생존자 수 | T1 |
| 안개 경고 | 안개 시작 시 "안개가 올라옵니다" 3초 + 안개 가장자리까지 높이 차 (m) 작게 상시 | T1 |
| 낙하 피해 피드백 | 화면 가장자리 빨강 플래시 + 바에 부상 조각 즉시 추가 | T0 |
| 채팅 | 좌하단 로그, Enter 입력 | T1 |
| 유령 뷰 | 흑백 비네트, "관전 중", 팀원 이름 클릭으로 카메라 이동 | T1 |
| 기절 뷰 | 화면 어둡게 + "기절 — 남은 시간 N초" + 바 표시 유지 | T1 |

## 3. 규칙

- uGUI + TextMeshPro. Canvas Scaler 1920×1080 Scale With Screen Size, match 0.5
- HUD 는 **오너 로컬 플레이어**만 생성 (`202` 2장). 팀원 마커는 다른 플레이어의 복제된 `PlayerState` 를 읽는다
- 색은 `VisualTheme` 에서. 상태이상 색은 `StatusEffectDef.color`
- 텍스트는 한국어. 폰트 Pretendard ⚠ (`102`)
- 모든 HUD 요소는 `HudRoot` 아래 하나의 Canvas. 디버그 오버레이(FPS, 시드, 해시, 상태)는 F3 토글, 별도 Canvas

## 4. 디버그 오버레이 (M0 부터)

- F3: 시드, 해시, 현재 상태(상태 기계), 스태미나 수치, 상태이상 목록, 네트워크 역할/핑, 안개 반경
- 이 오버레이가 있으면 워커의 "확인 방법"이 단순해진다 — M0 필수 산출물
